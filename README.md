# 古文字库系统

完整的古文字数据库系统，包含 839 个字头、5661 个字形，支持 7 个朝代（商、周、晋、楚、燕、秦、齐）。

## 🚀 快速开始

### 方式 1：使用启动脚本（推荐）

```bash
bash start_venv.sh
```

### 方式 2：使用部署脚本

```bash
bash deploy.sh
```

### 方式 3：手动启动

```bash
source venv_ancient/bin/activate
python3 app.py
```

## 📍 访问系统

启动后，打开浏览器访问：

```
http://localhost:5000/char_detail.html
```

## 🎯 主要功能

### 1. 字头搜索
- 支持按字头搜索
- 支持繁体字转换（齊→齐、週→周）
- 显示字头的拼音分组

### 2. 字形展示
- 按朝代分组显示字形
- 显示出处编码
- 支持图片加载

### 3. 注释系统
- 查看字头注释
- 查看注释来源
- 支持批量导入注释

### 4. API 接口
- GET `/api/search?q=<字符>` - 搜索字头
- GET `/api/char/<char>/annotation` - 获取注释
- POST `/api/char/<char>/annotation` - 创建/更新注释
- POST `/api/annotations/batch` - 批量导入注释

## 📝 使用示例

### 搜索字头

在页面上输入单个汉字，比如：
- `喜` - 显示 6 个朝代的字形
- `亥` - 显示 6 个朝代的字形
- `欬` - 显示秦朝的 1 个字形

### 查看注释

点击字头后，可以查看：
- 【注】部分（字头级别的注释）
- 字形演变（按朝代分组）
- 出处编码

## ⚠️ 已知问题

1. **图片和出处编码不匹配** - 某些图片显示可能不准确
2. **某些文件名为特殊字符** - 不影响功能，仅影响显示
3. **注释覆盖率低** - 原始数据中只有 230 条注释

## 🔧 故障排除

### 问题：无法启动服务

**解决方案：**
1. 检查 Python 版本：`python3 --version`
2. 检查虚拟环境：`ls -la venv_ancient/`
3. 检查数据库：`ls -la ancient_characters.db`
4. 检查图片目录：`ls -la extracted_final/字形图片/`

### 问题：图片无法加载

**解决方案：**
1. 检查图片目录是否存在
2. 检查图片文件是否完整
3. 查看浏览器控制台错误信息

### 问题：API 返回错误

**解决方案：**
1. 检查字符编码
2. 查看服务器日志
3. 验证数据库连接
